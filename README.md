# Mesa de Partes Digital - Municipalidad de Chorrillos

Prototipo en Python para el registro, validación y seguimiento de expedientes
de la Subgerencia de Trámite Documentario.

## Archivos
- main.py: menú principal y módulos del sistema
- validaciones.py: validación de DNI, RUC, celular y correo
- persistencia.py: lectura y escritura en expedientes.txt

## Ejecución
python main.py
